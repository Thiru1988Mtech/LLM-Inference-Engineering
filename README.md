\# LLM Inference Engineering



A 26-day hands-on learning journey covering LLM inference from fundamentals to production engineering.



\## Learning Goal



Understand how Large Language Model inference works from:



\- Tokens

\- Tokenization

\- Model forward pass

\- Logits and probabilities

\- Decoding

\- Autoregressive generation

\- KV Cache

\- Batching

\- GPU inference

\- Quantization

\- Inference runtimes

\- Performance optimization

\- Production inference architecture

\- Observability and deployment
